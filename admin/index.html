Conectar con GitHub (una sola vez)

Para que el panel pueda guardar fotos y cambios en GitHub, pega una llave de acceso. Esto lo hace una sola vez quien administra la cuenta. Después, el equipo entra solo con la contraseña.

  1. Abre crear llave en GitHub.
  2. En Expiration elige la fecha más lejana que permita.
  3. En Repository access elige Only select repositories y marca el repositorio del sitio.
  4. En Permissions → Contents, elige Read and write.
  5. Pulsa Generate token, cópiala y pégala abajo.
